# ARCHIO source fixes — 19 October 2026

## Changes

- Kept the hosting-level 404 response for unknown application paths and missing static assets, preserving a real HTTP 404 instead of turning every miss into a successful 200 response.
- Updated the static 404 page heading to `Not found` so it has the same clear, accessible label expected by the public-site checks.
- Added Vercel and preview routing for `/projects/:slug`, so an unknown project slug reaches the React app and receives project-specific `noindex` metadata and no canonical URL.
- Updated the hosting configuration test to cover the project-detail route patterns and static 404 heading.
- Updated the public E2E unknown-page test to distinguish the hosting-level 404 from the project-specific in-app not-found route.
- Made the mobile gallery E2E test wait for both gallery figures before measuring layout, avoiding a race against lazy route loading.
